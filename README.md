# scripts

Сборник скриптов для быстрой настройки Linux-серверов.

## Swapfile

Создаёт и включает swap-файл на 2048 МБ:

```bash
bash <(curl -fsSL raw.githubusercontent.com/jorasssip/scripts/main/swapfile.sh) --enable --size 2048
```
